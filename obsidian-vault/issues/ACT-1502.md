# ACT-1502: Sm-00 fails: no configuration for mcounteren read-only zero while U-mode is present

Sail assumed mcounteren fully writable; read-only-zero mcounteren is legal when U-mode exists. Sail 0.12 added mcounteren_writable_bits; a wrong value also makes Zicntr tests trap (ACT-1951).

## What fails

mcounteren reads back 0 (or fewer bits) where Sail expects the written value, or ZicntrS/U take an unexpected illegal instruction on a counter read.

## What the maintainers concluded

Configuration: set mcounteren_writable_bits in sail.json to the measured mask (closed as config issues in #1502 and #1951).

## How triage treats a match

Measure mcounteren's writable bits on the board and compare with sail.json.
