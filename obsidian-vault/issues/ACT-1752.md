# ACT-1752: ExceptionsSm-00.S: cp_misaligned_priority_load uses access-fault base address

cp_misaligned_priority_load used RVMODEL_ACCESS_FAULT_ADDRESS as its base, so the access was both misaligned and faulting.

## What fails

ExceptionsSm-00 expects load-address-misaligned (4); VF2 reports load access fault (5).

## What the maintainers concluded

The priority between the two is implementation-defined; Sail's priority configuration resolves it (SAIL-1793).

## How triage treats a match

Configure Sail's misaligned/access-fault priority for the board; not a hardware bug.
