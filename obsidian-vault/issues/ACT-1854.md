# ACT-1854: pmpsm cfg_A_tor_zero assumes 0x0 raises access fault

PMPSm_cfg_A_tor_zero checks that a TOR region in pmpaddr0 starts at address 0, so it accesses address 0 itself, not RVMODEL_ACCESS_FAULT_ADDRESS.

## What fails

The test fails or Sail aborts when the DUT has memory at address 0 and sail.json's memory map does not say so.

## What the maintainers concluded

jordancarlin: deliberate; a core with memory at 0 must not trap there and sail.json must map it. Fixed the fall-through in #1877.

## How triage treats a match

On a board with RAM at 0 (BPI-F3 K1), check the Sail memory map before suspecting PMP hardware.
