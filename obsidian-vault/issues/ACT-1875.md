# ACT-1875: Sv39 non-leaf D/A/U tests appear to require Privileged ISA 1.12 behavior for a 1.11 DUT

Tests that set D/A/U or other reserved bits in non-leaf PTEs need privileged 1.12 behavior; in 1.10/1.11 these bits are reserved and the walk may continue.

## What fails

A priv-1.11 core continues the page-table walk instead of raising a page fault when reserved PTE bits are set.

## What the maintainers concluded

Maintainers agreed: tests with reserved PTE bits run only for S 1.12+ (gated or excluded by version).

## How triage treats a match

On a priv-1.11 board these failures are expected: known deviation.
