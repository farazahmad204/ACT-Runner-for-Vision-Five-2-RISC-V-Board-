# ACT-1899: SsstrictS-00 assumes senvcfg is implemented on a Privileged ISA 1.11 target

SsstrictS-00 sweeps CSR 0x10A (senvcfg); priv-1.11 cores trap on it, so the trap count differs from Sail.

## What fails

SsstrictS-00 fails with a trap-signature pointer offset mismatch on a priv-1.11 board.

## What the maintainers concluded

The access stays in the test; with Sail 0.13 configured for priv 1.11 the model traps too and the signatures agree.

## How triage treats a match

If it still fails, sail.json's privileged_isa_version does not say 1.11 for this board.
