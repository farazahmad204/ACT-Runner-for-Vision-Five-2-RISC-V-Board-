# ACT-1924: SsstrictSm-03 ignores TIME_CSR_IMPLEMENTED=false and tests time CSR 0xC01

SsstrictSm-03 reads the time CSR (0xC01); the U74 (and P550) trap on it, where Sail and Spike return a value.

## What fails

csrr time raises illegal instruction on the board; the test expected a successful read.

## What the maintainers concluded

Maintainers kept the test: Zicntr requires time to be readable; the priv spec lets implementations trap and emulate it in M-mode firmware, which the bare runner does not do.

## How triage treats a match

Known deviation of these boards (time is emulated by firmware normally): not a hardware bug.
