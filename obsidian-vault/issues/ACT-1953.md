# ACT-1953: UDB/ACT lacks an independent vectored stvec.BASE alignment parameter

Our report: the U74 requires a 256-byte aligned vectored stvec base; ACT placed the S-mode trampoline at 0x80046540 and wrote stvec=0x80046541, which reads back 0x80046501, so interrupts enter elsewhere.

## What fails

InterruptsS-00 on VF2: 'Expected value 0x...0c041e99, Actual 0x...0d000663' after a vectored S-mode interrupt.

## What the maintainers concluded

jordancarlin agreed UDB needs STVEC_BASE_ALIGNMENT_VECTORED (direct mode needs only 4-byte alignment); fixed by riscv-unified-db #2090.

## How triage treats a match

With a UDB/ACT revision that has the parameter and the VF2 config setting 256, this should not recur; otherwise check the config. Compare with the WFI/MTIP race in ACT-1956.
