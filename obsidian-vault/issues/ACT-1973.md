# ACT-1973: Test expects that only the least sig 40 bits of the 44-bit field SATP.PPN to be writable.

satp.PPN is WARL: a core with fewer physical-address bits keeps fewer PPN bits. Sail 0.13 has a parameter for it (#1894) and ACT stopped requiring specific PPN values (#1973).

## What fails

satp_access tests read back fewer PPN bits than written.

## What the maintainers concluded

jordancarlin: because of the WARL constraints on satp.PPN ACT should not test that specific values are returned.

## How triage treats a match

PPN truncation is legal; set the Sail physical-address width for the board. (An ASID difference is SAIL-1846 instead.)
