# ACT-2494: [Bug] write to `mtime` doesn't need to be ordered before read from `time` csr

cp_mtime_write writes mtime over MMIO and then reads the time CSR without a fence, so the read may see the old value.

## What fails

Sm_mcsr_cntr-00 bin under cp_mtime_write reads a stale time value.

## What the maintainers concluded

Agreed; a fence was added in #2495.

## How triage treats a match

If seen, the ACT revision predates #2495.
