# SAIL-1793: Misaligned LR/SC cannot be configured to throw a page fault

Misaligned LR/SC to an address that also access-faults: Sail reported address-misaligned (cause 4), the U74 reports access fault (cause 5). Both priorities are allowed.

## What fails

Sail expects mcause=4 (load address misaligned); VF2 reports mcause=5 (load access fault) for an access that is both misaligned and faulting.

## What the maintainers concluded

The exception-priority table lets misaligned be above or below access/page faults. Sail 0.14 can translate misaligned LR/SC first: set memory.misaligned.exceptions.lrsc to "None" and the region attribute accordingly.

## How triage treats a match

Expected implementation choice. Configure Sail 0.14 for the board's priority; a cause 4 vs 5 mismatch on these tests is not a hardware bug.
