# SAIL-1845: Sm_mcsr_cntr-00 assumes 64-bit HPM counters; add a per-counter width parameter

HPM counters on the U74 are 40 bits wide; the test writes a 64-bit value and expects it back.

## What fails

Sm_mcsr_cntr-00 reads back mhpmcounter3/4 truncated to 40 bits.

## What the maintainers concluded

Counter width is implementation-defined. Sail closed this with #1840; per-counter widths are tracked in ACT-2011 (UDB support added).

## How triage treats a match

A 40-bit HPM readback on VF2 is legal; see ACT-2011.
