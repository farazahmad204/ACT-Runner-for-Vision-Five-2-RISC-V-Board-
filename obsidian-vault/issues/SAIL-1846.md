# SAIL-1846: Make satp.ASID width configurable, including ASIDLEN=0

The U74 implements ASIDLEN=0 (satp.ASID reads 0); Sail kept all 16 ASID bits.

## What fails

sv39_satp_access_test reads satp.ASID back as 0 on VF2 while Sail returns the written bits.

## What the maintainers concluded

ASIDLEN is implementation-defined (0 allowed). Requested a Sail config for ASID width; closed as done.

## How triage treats a match

satp.ASID reading 0 on VF2 is legal; configure Sail's ASID width for the board.
