# SAIL-1846: Make satp.ASID width configurable, including ASIDLEN=0

The U74 implements ASIDLEN=0 (satp.ASID reads 0); Sail kept all 16 ASID bits.

## What fails

satp_access tests (Sv_sv39_satp_access_Smode, SvSm_sv39_satp_access_Mmode) read satp.ASID back as 0 on VF2 while Sail returns the written bits (e.g. expected bit 44 set).

## What the maintainers concluded

ASIDLEN is implementation-defined (0 allowed). Sail gained an ASID width option (asidlen); closed as done.

## How triage treats a match

satp.ASID reading 0 on VF2 is legal. The VF2 sail.json still says asidlen 16 (VER-20261009-vf2-sail-json-h-asid): set it to 0. Verdict 'Test or ACT issue' (config).
