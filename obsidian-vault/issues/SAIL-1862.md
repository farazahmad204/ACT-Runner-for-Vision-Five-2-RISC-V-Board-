# SAIL-1862: Priv spec 1.11 exception code 16 through 23 should all be reserved

In priv 1.11 exception codes 16-23 are reserved; Sail let mcause hold 19 under a 1.11 config.

## What fails

Sm_mcause-00 writes cause 19 and expects it back; a priv-1.11 core legalizes it (U74 reads 0x3).

## What the maintainers concluded

Reserved/WLRL values need not read back. ACT stopped testing that cause without Sm 1.13 (#2134); see ACT-2010.

## How triage treats a match

mcause readback of a reserved code differing from Sail is legal on priv 1.11.
