# SAIL-1904: Sail configuration cannot model specification-permitted VF2/U74 misaligned AMO exception behavior

The U74's misaligned-AMO exception policy (access fault to I/O, misaligned to DRAM, misaligned when translation fails) cannot be configured in Sail.

## What fails

Misaligned AMO tests expect a different exception cause than VF2 reports, depending on the target region and translation result.

## What the maintainers concluded

Open. Maintainers note that implementations supporting misaligned accesses only in some regions must translate first, which makes a page fault the expected result when translation fails; the discussion on the exact priority continues.

## How triage treats a match

Not proven a hardware bug; check the region and translation result before concluding. Reference model cannot express it yet.
